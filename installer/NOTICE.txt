Wave FM-1 Preview 0.2.2 - Experimental Windows x64 VST3

Close Ableton Live and other hosts before installing or uninstalling.
Default: C:\Program Files\Common Files\VST3\Wave FM-1.vst3
Administrator access is required. Live can discover this plugin on its next
system VST3 scan. No Ableton files, preferences or projects are changed.
No shared runtimes, drivers, services or antivirus changes are installed.

Uninstall preview 0.1.0 from Windows Settings > Apps first to avoid duplicate
copies. Keep your projects and exported .fm1save files. The new installer
refuses to overwrite an existing folder not managed by this installer.

The instrument appears as FM-1 by fm1-emu. Its emulator and original panel are
by Joakim Eriksson. The repository owner maintains this distribution and is
not credited as author of the emulator, firmwares or instrument. See
licenses/AUTHORS.md and THIRD_PARTY_NOTICES.md. The offline menu includes 23 firmware packages. Original
authors, licences and full sources are included in the bundle under
Contents/Resources. See FIRMWARES.md for the full list. Manual firmware/save
loading is retained. Six reference colour palettes are available per instance.
Changing firmware resets only that instance: export what you wish to keep.

MIDI / Live shows labelled assignable host controls. Community firmwares is an
optional online browser, with 83 references and direct author GitHub alternatives.
The main firmware download prefers the author release, reports the saved path
or an explicit error, and can reuse an already identical .fwsc without overwriting it.
Only explicit checks/downloads use the network. External packages are saved to
a user-selected new .fwsc file, never automatically loaded or added to this installer.
Their original authors and terms remain applicable; availability is not full
functionality or security verification. See the repository's MIDI_LIVE.md and
COMMUNITY_BROWSER.md guides. Closing the last instance waits for active jobs
to finish so the host cannot unload code still used by a download thread.

Test in an empty Live Set with important projects closed and backed up.
No experimental plugin can guarantee zero risk inside a DAW.
Uninstall Wave FM-1 Preview from Windows Settings > Apps. It removes only
this product's installed files and registration, not your projects or exports.
